BERNUD · PRIVACY POLICY

Last updated 24 October 2026.

Bernud is a private personal assistant built for and used only by Nicholas at Cory Car Paints Ltd, Jersey. It is not offered to the public.

What Bernud accesses

  • Gmail (read-only): with the account owner's consent, Bernud reads messages in corycarpaints@gmail.com using the gmail.readonly permission, to summarise mail and prepare a morning business brief. It cannot send, delete, label or change any email.
  • Google Drive (read-only): one shared Cory Car Paints reference folder, used for prices, product and data sheets.

How data is used and stored

  • Email and document content is used only to answer the owner's own questions and produce his brief. It is not sold, shared, or used for advertising or to train AI models.
  • Email content is processed when a request is made and is not stored in bulk. The written briefs and an encrypted Google access token are stored in a private database hosted on Render.
  • Requests are processed by the services that run Bernud: Render (hosting), ElevenLabs (voice agent) and the language model provider it uses.

Google API Services User Data Policy

Bernud's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google account's Third-party connections page. Stored briefs can be deleted on request.
